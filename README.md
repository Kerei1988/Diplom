# Анализ рынка вакансий Data Science

Дипломный проект по Python-разработке.

## 📋 Описание

Проект загружает данные о вакансиях Data Science, обрабатывает информацию о зарплатах, проводит аналитику и визуализирует результаты.

### Возможности:
- Загрузка данных через Pandas или Dask
- Парсинг зарплат (месячные, почасовые, диапазоны)
- Топ-10 локаций, должностей, работодателей
- Средняя зарплата по рынку
- Рейтинг компаний с фильтром
- Визуализация (круговые и столбчатые диаграммы)
- Сравнение производительности Pandas vs Dask
- Сохранение результатов в CSV и PNG

## 🛠 Стек

- Python 3.11+
- Pandas — обработка данных
- Dask — работа с большими объёмами (опционально)
- Matplotlib — визуализация

## 🚀 Установка и запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/Kerei1988/Diplom.git
   cd Diplom

2. Создать виртуальное окружение и установить зависимости:

bash
python -m venv .env
.env\Scripts\activate
pip install -r requirements.txt

3. Поместить файл Data-Science-Jobs.csv в папку data/

4. Запустить:
bash
python src/main.py

5. Результаты будут в папке src/output/


## Результаты

После запуска в папке src/output/ создаются:

top_locations.csv / .png — топ-10 локаций по найму

top_jobs.csv — топ-10 должностей

best_rated_companies.csv / .png — компании с рейтингом ≥ 4.0

report.txt — сводный отчёт со сравнением производительности
